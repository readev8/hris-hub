# PROJECT CONSTITUTION

## Purpose
Dokumen ini adalah aturan utama AI sebelum melakukan perubahan apa pun.

## Mandatory Workflow
1. Scan legacy project.
2. Scan Bug Report.
3. Scan Request Improvement.
4. Analisis impact.
5. Buat proposal.
6. Tunggu approval.
7. Implementasi.
8. Regression test.
9. Release note.

## Golden Rules
- Jangan membuat tabel baru jika dapat menggunakan tabel existing.
- Jangan mengubah API tanpa impact analysis.
- Semua perubahan harus memiliki Change Request.
- Reuse lebih diutamakan daripada rewrite.
